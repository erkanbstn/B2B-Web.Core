# Sipariş takip

Müşteri ve yönetici paneli olan sipariş takip sitesi.

## Ne var

Yönetici girişi, müşteri paneli ve sipariş paneli ayrı controller'lardadır.

## Çalıştırma

```powershell
dotnet run --project SiparisTakipSistemiCore/SiparisTakipSistemiCore
```

## Yığın

.NET 5, ASP.NET Core MVC, Entity Framework Core ve SQL Server.
